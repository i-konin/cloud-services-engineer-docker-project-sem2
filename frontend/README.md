# Оптимизация образа Frontend (Vue)


**Техники оптимизации:**
*   **Multi-stage**: Сборка приложения через `node:26-alpine`. В финальный образ (на базе `nginx:alpine`) копируется только папка `dist` (результат `npm run build`).
*   **Удаление лишнего**: В финальном образе отсутствует Node.js, npm, кэши пакетов и исходный код SPA.

**Размер итогового образа:** `~60MB`
