# Оптимизация образа Backend (Go)

**Техники оптимизации:**
*   **Multi-stage**: Сборка бинарного файла происходит в среде `golang:1.22-alpine`, а для запуска используется легковесный `alpine:latest`. Это исключает из итогового образа Go-компилятор и исходный код.
*   **Эффективное кэширование**: Команды `COPY go.mod go.sum ./` и `RUN go mod download` стоят перед копированием исходного кода. Это предотвращает переустановку зависимостей при каждом изменении кода.
*   **Бинарное связывание**: `CGO_ENABLED=0` позволяет создавать полностью статический бинарный файл, не требующий системных библиотек GLIBC.

**Размер итогового образа:** `~40MB`
